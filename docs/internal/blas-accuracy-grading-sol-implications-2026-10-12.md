# BLAS 精度分级对 SOL 排名与正确性关系的启示

日期：2026-10-12。分析基于当前工作区及 HEAD
`e35d046ee9c64c310ff3be41fe0a78b00bb993b3`；工作区存在其他未提交改动。
本次仅研究，没有重测 SOL 提交、运行 GPU 或修改实现。

## 判断

[How to grade the accuracy of the BLAS](https://arxiv.org/html/2609.12307)
可以解释一部分“速度排名高，但换输入后正确性脆弱”的机制，尤其是数值精度保证
与有限测试通过之间的差距。它没有审计 SOL 榜单，不能用于判定具体团队、提交或
违规比例，也不能证明某个候选的加速因果上来自精度退让。

## 论文证据与适用边界

- §3 的 A/B/C 是不同强度的误差界，分别涉及逐元素、行列尺度及整体范数。
  它们不是正确、勉强正确、错误三个等级；较弱界仍可满足应用要求。
  A 也不要求正确舍入、逐位匹配或在消去后近零结果上保持很小的相对误差。
- §4–5 以结构化输入检验承诺：稀疏结构、微小非零输出、宽动态范围、缩放和置换。
  §5.2 表 2 中，n=32 的 Strassen + outer scaling + zeroing 在 Test 1a/1b
  分别有 0/768、0/16 个错误输出位置，Test 1c 则有 8/16。这里是指定位置的
  计数，不是 SOL 任务失败率。修补已知测试可能保留未覆盖的数值弱点。
- §2 明确不能通过有限黑盒测试证明全域正确，也不严格保证无法 gaming。
  故意利用测试和无意过拟合测试都可能出现。针对真实难输入的可靠 fallback
  属于合法算法设计，不能仅凭存在分支认定作弊。
- §5.3 所测生产 DGEMM 库在指定尺寸和尺度范围内均取得 A；论文没有证明
  常用生产库普遍数值不可靠。其 FP64 试验尺度不能直接复制到 BF16/FP8。

来源：[论文全文，§2–5、§10–12](https://arxiv.org/html/2609.12307)。
[官方代码](https://github.com/Reference-LAPACK/grading-the-BLAS)提供 DGEMM
测试，不能直接视为任意 ROCm 算子的通用 correctness 插件。

## 与 SOL 的联系：推论而非已验证归因

[SOL 原论文 §4.3–4.4](https://arxiv.org/html/2603.19173v1)描述了正确性门槛、
多种子验证和按 workload 设置的容差；§4.4.1 允许保持输入输出 dtype、满足
规定容差的内部降精度。因此，不能把所有低精度加速都归类为作弊。

可检验的机制假设是：搜索优化的是“通过当前有限测试之后的速度”。如果检查对
某类精度退让不敏感，搜索可能保留更快、但有效数值保证更弱的实现。这解释了
高分与脆弱性为何可以共存，不证明这种机制在榜单上发生的频率或具体责任。

需区分四类情况：

| 情况 | 本文帮助 |
| --- | --- |
| 内部截断、累加精度、缩放敏感性导致误差 | 直接提供分析和诊断思路 |
| 忽略参数、少算专家、错误 mask | 需要算子语义检查，BLAS 等级不能代替 |
| 缓存答案、篡改 grader、绕过计时 | 需要执行隔离及完整性证据 |
| 声明域以外的 shape 或输入失败 | 先判断是否超出契约，不能直接称违规 |

## 当前项目的具体落点

[correctness.py](../../src/sol_execbench/core/bench/correctness.py)以
`atol + rtol * abs(reference)` 判定逐元素容差，再应用匹配比例、可选最大误差
上限和连续遗漏保护。这些检查有价值，但不等价于 BLAS 的误差界分级。
独立 reference 和新随机种子也不能自行扩展输入生成器的语义覆盖。

建议首先建立 GEMM 数值诊断，保持原 SOL 分数口径可对照：

1. 冻结候选、评估器及声明输入域，保存原基准结果。
2. 在域内追加普通随机、宽动态范围、正负消去、稀疏微小非零输入；结合
   成对缩放和内维置换，避免只增加同分布随机种子。
3. 使用独立高精度参考，并依据 dtype、尺寸和所承诺误差界解释误差；不能
   简单收紧所有算子的统一 rtol，也不能把 A 界直接套给任意融合算子。
4. 分开记录原规则通过、声明域内契约违反、数值适用范围限制和域外失败。
   保存反例输入、误差指标及输出。在相同输入与精度契约下复测延迟。
5. 若需归因速度来源，增加只改变精度策略的配对实现/干预；单独发现反例
   还不足以证明全部加速来自降低正确性。
